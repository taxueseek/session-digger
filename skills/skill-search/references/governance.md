# Governance Model

## 适合治理的 skill

- 会被多人使用
- 输出影响面较大
- 容易出现描述漂移

## 治理重点

- 归属
- 评审节奏
- 版本记录
- 证据留存
- 权限边界
- 回滚边界
- 公开 claim 是否有证据支持

治理不是为了复杂，而是为了不走样。

## 缺失证据

以下内容如果没有真实证据，必须标记 `missing evidence`：

- provider-backed model run
- human blind review
- install simulation / install proof
- telemetry or adoption drift
- secret scan
- public release / PR merge
